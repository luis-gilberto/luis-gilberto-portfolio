Brand Guidelines 2025

The Orchestrator

Two Voices. One Vision.

This isn't a brand with indecisive typography. This is a brand that knows when to tell a story and when to build a system. Welcome to a design philosophy that conducts emotion and architecture in perfect harmony.

Version 2.0 • December 2025

Brand Philosophy

Latin warmth meets Scandinavian minimalism

Every element earns its place. Sophisticated design with purposeful restraint. Two typefaces. Two personalities. One orchestrated experience that bridges creative vision and systematic intelligence.

The Storyteller

Playfair Display

Editorial sophistication and emotional depth. The voice that makes you pause, lean in, and feel something. Reserved for narrative moments where humanity takes center stage.

When to use:

  • Hero headlines that need emotional weight
  • About page storytelling moments
  • Pull quotes and featured insights
  • Personal narrative headers

The Architect

Big Shoulders Display

Structural boldness and systematic clarity. The scaffolding made visible, the framework that holds everything together. Used for navigation, organization, and systematic intelligence.

When to use:

  • Navigation and section headers
  • Portfolio project titles
  • Service/product names
  • Timeline milestones and card titles

The Translator

Inter

The connective tissue between emotion and structure. The bridge that makes everything readable, accessible, and human at scale. Body copy, UI, metadata—this is where clarity lives.

When to use: All body copy, UI elements, buttons, form labels, metadata, captions, and supporting text. Maximum line length of 65 characters for optimal readability.

Hybrid System

The Signature Move

When you need both sophistication and structure in the same moment, use the "One Accent Word" technique. Lead with Playfair for emotional weight, follow with Big Shoulders for structural clarity.

Example 1: Hero Lockup

Syntax MEETS STORIES

The first word (Syntax) gets the editorial treatment—italic, sophisticated, human. The second phrase (MEETS STORIES) becomes the structural anchor—uppercase, geometric, bold. This creates visual tension that resolves into harmony.

Example 2: Section Header

Strategic PARTNERSHIPS

Use sparingly—3-4 times per page maximum. This is a signature move, not a baseline. Think of it as the accent color of your typography system. Overuse dilutes the impact.

Example 3: Portfolio Feature

Attention ARCHITECTURE

Works best when the first word is emotional/conceptual (Attention, Strategic, Vision) and the second is concrete/systematic (Architecture, Partnerships, Intelligence).

Color System

Strategic Restraint

Five colors. Infinite impact. Each color is tied to a specific emotional and functional purpose. Use sparingly for maximum effect.

CORAL

Coral

#F96F6E

Strategy, leadership, primary CTAs. Use for Playfair Display accents and emotional anchor moments.

TEAL

Teal

#2ED3C6

Creative execution, innovation, delivery. Use for Big Shoulders Display accents and structural elements.

FLOW

Gradient

Coral → Teal

Collaboration moments. Use sparingly for hybrid lockups or when emotion and structure converge.

DEPTH

Deep Blue

#2C3E50

Backgrounds, subtle accents, depth. Professional foundation that grounds the warmer tones.

GRAY

Cool Gray

#B2B2BB

Secondary text, borders, subtle UI elements. The neutral translator between bold statements.

Color Pairing Rules

  • High Impact: Deep Black + Coral (primary CTAs, hero moments)
  • Professional: Deep Blue + Cool Gray (backgrounds, structure)
  • Clean Energy: White + Coral (landing pages, invitations)
  • Sophisticated: Deep Black + Cool Gray (editorial, body content)
  • Collaboration: Coral-to-Teal Gradient (hybrid lockups, converge moments)

Implementation

CSS Variables & Code

Semantic naming that maps to intention, not just visual properties. This makes the system scalable and the rules enforceable.

:root { /* Typography */ --font-narrative: 'Playfair Display', serif; --font-architect: 'Big Shoulders Display', sans-serif; --font-system: 'Inter', sans-serif; /* Colors */ --coral: #F96F6E; --teal: #2ED3C6; --deep-blue: #2C3E50; --cool-gray: #B2B2BB; --ink: #FFFFFF; --ink-dim: rgba(255,255,255,0.85); } /* Semantic Typography Classes */ .heading-narrative { font-family: var(--font-narrative); font-weight: 800; } .heading-architect { font-family: var(--font-architect); font-weight: 800; text-transform: uppercase; letter-spacing: 0.02em; } .body-text { font-family: var(--font-system); max-width: 65ch; line-height: 1.8; } /* Hybrid Lockup System */ .hybrid-heading .narrative { font-family: var(--font-narrative); font-style: italic; color: var(--coral); } .hybrid-heading .architect { font-family: var(--font-architect); text-transform: uppercase; letter-spacing: 0.02em; color: var(--ink); }
