Troubleshooting Guide

Problem: Images not loading

Symptoms: Broken image icons, missing timeline era images

Solution:

  • Verify assets/images/ directory exists
  • Check file names match exactly (case-sensitive)
  • Ensure all required images are present
  • Check file permissions (should be readable)

Problem: Mobile modals not opening

Symptoms: Timeline cards don't respond to touch on mobile

Solution:

  • Clear browser cache on mobile device
  • Test in different mobile browsers
  • Ensure JavaScript is enabled
  • Check for JavaScript errors in console

Problem: Overlay buttons not working

Symptoms: Can't close overlay, stuck on loading screen

Solution:

  • Hard refresh the page (Ctrl+F5 or Cmd+Shift+R)
  • Check browser console for JavaScript errors
  • Try pressing Escape key to close overlay
  • Ensure you're using the correct new file

Emergency Rollback Plan

If something goes wrong, quickly restore the previous version:

# Find your backup directory
ls -la timeline_backup_*

# Restore from most recent backup
BACKUP_DIR=$(ls -td timeline_backup_* | head -1)
echo "Restoring from: $BACKUP_DIR"

# Restore the timeline file
cp "$BACKUP_DIR/timeline.html" ./timeline.html

# Restore any other files if needed
cp -r "$BACKUP_DIR/styles" ./ 2>/dev/null || true
cp -r "$BACKUP_DIR/scripts" ./ 2>/dev/null || true
cp -r "$BACKUP_DIR/timeline" ./ 2>/dev/null || true

echo "✅ Rollback complete - previous version restored"
