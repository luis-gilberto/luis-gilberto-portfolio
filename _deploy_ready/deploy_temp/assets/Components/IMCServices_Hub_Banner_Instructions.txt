## Instructions for Implementation

1. Locate the IMC Services Hub banner section:
   - File path: `/IMCServices/index.html`  
   - Look for the current banner `<section>` with the class name: `hero-banner` (or similar).

2. Inside that section, replace the **headline H2** and **subhead paragraph** with the chosen option above.  
   Example structure:
   ```html
   <section class="hero-banner">
     <h2>Where <span class="highlight">clarity</span> meets growth</h2>
     <p>Build marketing systems that scale with your ambition.</p>
   </section>
   ```

3. Ensure the highlight styling matches the other banners:
   - CSS rule should already exist:
     ```css
     .highlight {
       color: #F96F6E; /* Coral accent */
       font-weight: 600;
     }
     ```
   - If missing, add this to your global stylesheet (`/styles/main.css`).

4. Save changes and redeploy the site.  
   - In Trae, run:
     ```
     git add .
     git commit -m "Update IMC Services Hub banner with refined messaging"
     git push
     ```
