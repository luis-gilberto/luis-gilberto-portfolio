BRAND SYSTEM

IMC Services Guidelines

A comprehensive design system that ensures consistency across all IMC Services touchpoints, from ScopeIQ Wizard to Marketing Toolkit.

FOUNDATION

Core Principles

CLARITY

Clarity first

Typography and color must clarify, not decorate. Every design decision serves understanding.

FOCUS

One accent per heading

Only one word per title gets color. This creates intentional emphasis and visual hierarchy.

HIERARCHY

Hierarchy by space

Use padding and line length as primary hierarchy cues; weight and color are secondary tools.

ADAPTIVE

Desktop drama, mobile calm

On desktop, accents can flex. On mobile, simplify accents and collapse to single highlights.

TYPOGRAPHY

Type Stack

EYEBROW
BRAND SYSTEM

Inter 600, ALL CAPS, tight tracking. 1–3 words max.

TITLE

Strategic Frameworks

Playfair Display or Recoleta, sentence case, one accent word only.

DESCRIPTOR

One sentence formula: what it is + how it delivers + in what form.

Inter, clear structure for immediate understanding.

BODY / UI

Inter, 400–500 weight, ≤65ch line length for optimal readability. This ensures comfortable reading across all devices and maintains focus on the content.

COLOR SYSTEM

Color Roles

Coral (#F96F6E)

STRATEGY / LG

Use for thinking, frameworks, positioning. Represents strategic insight and leadership guidance.

Teal (#2ED3C6)

CREATIVE / 100%

Use for execution, design, deliverables. Represents creative output and tangible results.

Gradient

PARTNERSHIP / OVERLAP

Use sparingly for collaboration moments. Where strategy meets creative execution.

Ink / Neutrals

SUPPORTING

Supporting text, calm backgrounds. The foundation that lets color accents shine.

IMPLEMENTATION

Application Rules

HEADERS

Contextual Color

One accent word only. Process = Coral, Collaboration = Gradient, Results = Teal.

CARDS

Unified Role Color

Icon + tagline + headline = same role color. Body text neutral. Center icons/headlines, left-align body.

PROOF / RESULTS

Alternating Pattern

Title neutral with gradient accent. Cards alternate between coral and teal role colors.

CTA SECTIONS

Hierarchical CTAs

Punch phrase = gradient. Primary CTA = coral. Secondary CTA = teal border.

BEST PRACTICES

Do's & Don'ts

✓ Do

  • Keep titles ≤2 lines desktop, ≤3 lines mobile
  • Use space before color/weight
  • Use gradient sparingly so it feels intentional

✗ Don't

  • Rainbow multiple words in one headline
  • Use all caps in titles (eyebrow only)
  • Stack multiple CTAs above fold on mobile
DEVELOPMENT

CSS Tokens

:root { --coral: #F96F6E; /* Strategy */ --teal: #2ED3C6; /* Creative */ --ink: #FFFFFF; /* Body */ --ink-dim: rgba(255,255,255,.85); /* Subtext */ } .text-coral { color: var(--coral); } .text-teal { color: var(--teal); } .text-gradient { background: linear-gradient(90deg, var(--coral), var(--teal)); -webkit-background-clip: text; -webkit-text-fill-color: transparent; }
