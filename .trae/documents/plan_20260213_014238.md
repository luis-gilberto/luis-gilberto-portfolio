# Structural Stabilization & Navigation Redesign (V5.7 Standard)

## Phase 1: Global Identity & Wayfinding

1. **Standardize Project Identity**: Ensure all project views (Admin and Partner) use the centered `[Client Name] // [Project Title]` headline with `text-zinc-400` and `Inter Medium`.
2. **Unified Phase Labels**: Move engagement phase labels exclusively to the `TopNavBar`. Remove scattered "Discovery" or "Status" labels from page content to reduce noise.
3. **Global Breadcrumbs**: Implement a single, robust breadcrumb system that anchors every view to its parent context (Dashboard → Strategy Engine → Project).
4. **Wayfinding Contract**: Ensure the `← Back to projects` link is the universal exit path for all project-level work.

## Phase 2: Typography & Editorial Scale

1. **Normalize Heading Scale**: Eliminate oversized headings (4xl+). Standardize on `text-2xl` for primary titles and `text-[11px]` bold for section labels.
2. **Editorial Body Standards**: Force all strategic narratives (AI or Human) to use the "Artifact" style: `text-zinc-300`, `text-lg`, `leading-relaxed`, and `font-serif`.
3. **Technical Metadata**: Move Project IDs and system references to a consistent technical footer (`text-[9px]`, mono, low opacity).

## Phase 3: System Logic & Persistence

1. **Stabilize Assessment State**: Remove `localStorage` dependencies from the Strategy Engine. Ensure all progress, scores, and answers are persisted directly to the `assessment_sessions` database table.
2. **Source of Truth**: Ensure "Consultant Secret Sauce" (`certifiedNarrative`) is the immutable source for all results views, preventing resets during Partner previews.
3. **Real Client Management**: Replace hardcoded client placeholders with the real `dbClients` ledger. Link projects directly to these client records to drive context.

## Phase 4: Layout Density & Visibility

1. **Vault Scannability**: Refactor the Partner Vault from a compressed table into a readable editorial list. Prioritize scannability and preview accessibility.
2. **Command Center Ledger**: Reconfigure the Dashboard to act as a live engagement ledger, surfacing assessment progress and intelligence scores as primary metrics.
3. **Knowledge Base Rebranding**: Rename "Pricing KB" to **Strategy Enablement Hub**. Restyle the view to match the premium editorial workspace standard.

## North Star Test

* **Where am I?** (Centered Project Identity + Top NavBar Phase)

* **What is this for?** (Minimalist TOC Switcher + Section Labels)

* **What is next?** (Clear, state-aware primary CTA in the content stage)
