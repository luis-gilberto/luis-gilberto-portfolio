# Brand Guidelines — Trinity Framework Update

## Overview
Updated brand guidelines to consistently reflect “Three Perspectives. One Vision.” throughout the entire page, replacing the inconsistent “Two Voices” messaging.

## Key Changes
1. Hero Section
   - Before: “Two Voices. One Vision.”
   - After: “Three Perspectives. One Vision.”
   - Description: “A single source of truth that orchestrates strategy, craft, and clarity—the three lenses that transform complexity into coherent, compelling experiences.”

2. New Section: The Trinity Framework
   - Added explainer immediately after hero:
     - The Storyteller = The Systems Thinker (Coral)
       - Strategic vision, emotional intelligence
       - “Where are we going and why does it matter?”
     - The Architect = The Curator (Teal)
       - Detail-oriented, structural precision
       - “How do we craft this with excellence?”
     - The Translator = The Bridge Builder (Cloud Dancer)
       - Connects opposites, makes complexity simple
       - “How do I make this work for everyone?”
   - Key Quote: “Strategy without craft is vaporware. Craft without translation is inaccessible. Translation without strategy is shallow. You need all three.”

3. Typography Section Enhanced
   - Description: “Each typeface embodies one of the three perspectives…”
   - Explicit mapping:
     - Playfair Display = Embodies the Systems Thinker
     - Big Shoulders Display = Embodies the Curator
     - Inter = Embodies the Bridge Builder
   - Pull Quote: “Every typeface has a purpose. Every moment has a perspective.”

4. Philosophy Section Enhanced
   - Mission: “To bridge the gap between creative vision and business impact through three integrated perspectives…”
   - Core Values:
     - Integration (NEW — first value)
     - Excellence
     - Clarity
     - Impact

5. Color System Enhanced Mapping
   - Description: “Each primary color maps to one of the three perspectives…”
   - Names:
     - Coral → The Storyteller
     - Teal → The Architect
     - Cloud Dancer → The Translator
   - Gradient: “Convergence — where perspectives converge”

## Visual Structure
- New CSS classes:
  - `.trinity-framework` (container with coral accent)
  - `.trinity-grid` (3-column responsive grid)
  - `.trinity-card` (individual perspective cards)
  - Mobile responsive: 3 → 2 → 1 columns with media queries

## Consistency Achieved
- Hero establishes “Three Perspectives. One Vision.”
- Trinity Framework explains methodology
- Typography maps fonts to perspectives
- Color system maps primary colors to perspectives
- Philosophy emphasizes integration
- Replaced references to “voices” with “perspectives” where appropriate

## Positioning Outcome
- Eliminates contradiction (no more “two voices” vs “three voices”)
- Establishes methodology (Trinity Framework)
- Creates consistency across typography, color, and philosophy
- Positions differentiation (“I move fluidly between three perspectives”)
- Avoids multiple-personality concern (integration, not fragmentation)
