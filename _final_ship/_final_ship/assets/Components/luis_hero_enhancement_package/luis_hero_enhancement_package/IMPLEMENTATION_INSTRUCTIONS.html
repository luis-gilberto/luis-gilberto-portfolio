3 JAVASCRIPT ENHANCEMENT

ADD to existing script section in about.html

// ADD this inside your existing DOMContentLoaded event listener

// Microsoft-inspired floating elements
function createFloatingElements() {
    const hero = document.querySelector('.about-hero');
    if (!hero) return;
    
    for (let i = 0; i < 3; i++) {
        const element = document.createElement('div');
        element.style.cssText = `
            position: absolute;
            width: 20px;
            height: 20px;
            background: rgba(249, 111, 110, 0.1);
            border-radius: 4px;
            top: ${20 + Math.random() * 60}%;
            left: ${10 + Math.random() * 80}%;
            animation: float-subtle ${8 + Math.random() * 4}s ease-in-out infinite;
            z-index: 2;
        `;
        hero.appendChild(element);
    }
}

// Add floating animation CSS
const style = document.createElement('style');
style.textContent = `
    @keyframes float-subtle {
        0%, 100% { transform: translateY(0px) rotate(0deg); opacity: 0.3; }
        50% { transform: translateY(-20px) rotate(180deg); opacity: 0.1; }
    }
`;
document.head.appendChild(style);

// Initialize after page load
setTimeout(createFloatingElements, 1000);

4 IMPLEMENTATION CHECKLIST

TROUBLESHOOTING

If background image doesn't appear: Check the file path in CSS matches your actual file location

If text is hard to read: Increase the opacity values in the overlay gradients

If animations are choppy: Reduce animation duration or disable on mobile

If mobile looks weird: Verify the background-position adjustment is working

  • ✅ Luis's portrait and Microsoft apps visible but subtle
  • ✅ Text remains readable with proper contrast
  • ✅ Subtle floating animations add professional polish
  • ✅ Mobile-responsive with proper image positioning
