STEP 3: ADD JAVASCRIPT THEME SWITCHER
-------------------------------------
Add this JavaScript:

<script>
// Theme-aware transparent video switcher
function updateInsightsVideo() {
    const video = document.querySelector('[data-theme-video]');
    if (!video) return;
    
    const theme = document.documentElement.getAttribute('data-theme') || 'light';
    const isPlaying = !video.paused;
    const currentTime = video.currentTime;
    
    if (theme === 'dark') {
        video.innerHTML = '<source src="/assets/insights-title-dark-transparent.webm" type="video/webm">';
    } else {
        video.innerHTML = '<source src="/assets/insights-title-light-transparent.webm" type="video/webm">';
    }
    
    video.load();
    video.currentTime = currentTime;
    if (isPlaying) {
        video.play().catch(() => {});
    }
}

// Run on page load
document.addEventListener('DOMContentLoaded', updateInsightsVideo);

// Connect to your theme toggle
// Add updateInsightsVideo(); to your existing theme toggle click handler
</script>

===========================================
TECHNICAL NOTES
===========================================

WHY WEBM ONLY (NO MP4):
- MP4 does not support transparency (alpha channel)
- WebM VP9 codec supports alpha transparency
- Modern browser support: 95%+ (all Chrome, Firefox, Edge, Safari 16+)
- Acceptable tradeoff for premium visual quality

ALPHA CHANNEL METADATA:
- Videos have ALPHA_MODE=1 flag set
- Browsers automatically render transparency
- No additional CSS needed for transparency

FILE SIZES:
- Light mode: 2.2 MB (high quality, smooth animation)
- Dark mode: 1.7 MB (optimized, identical timing)
- Poster images: ~115 KB each (fast load)
- Total package: ~4.1 MB (acceptable for hero animation)

PERFORMANCE:
- Videos load progressively (streaming)
- Poster images show immediately
- Hardware accelerated rendering
- Mobile optimized

===========================================
TROUBLESHOOTING
===========================================

PROBLEM: Still seeing white/black box
→ Browser doesn't support WebM VP9 alpha (rare)
→ Check browser version (update to latest)
→ Test in Chrome/Edge (guaranteed support)

PROBLEM: Video not playing
→ Check file paths match your assets directory
→ Verify autoplay is working (requires muted attribute)
→ Check browser console for 404 errors

PROBLEM: Old animation still showing
→ You didn't delete old SVG code
→ Search HTML for "thread-svg" and DELETE ALL
→ Search CSS for "thread-" and DELETE ALL
→ Hard refresh (Cmd+Shift+R / Ctrl+Shift+F5)

PROBLEM: Theme switching not working
→ Verify updateInsightsVideo() is being called
→ Check data-theme attribute changes on <html>
→ Add console.log to debug function
