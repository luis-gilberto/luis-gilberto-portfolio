Icon System

Custom SVG icons in brand colors only. No emojis, ever.

Philosophy

Our icon system uses clean, geometric SVG designs that align with our sophisticated visual language. Emojis introduce unwanted colors and inconsistent styling—we use custom icons exclusively to maintain brand integrity.

Technical Specifications

  • Format: SVG only (no PNG, no emojis)
  • Colors: Coral (#F96F6E), Teal (#2ED3C6), White (#FFFFFF)
  • Stroke width: 2px standard
  • Line caps: Rounded (stroke-linecap="round")
  • Default size: 64px × 64px (48px small, 80px large)
  • ViewBox: 0 0 24 24 (scalable)

Implementation

     fill="none" stroke="#F96F6E" stroke-width="2" 
     stroke-linecap="round" xmlns="http://www.w3.org/2000/svg">
    <!-- Icon paths here -->
</svg>

<!-- CSS for Icon Sizing -->
.icon {
    width: 64px;
    height: 64px;
    transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
}

.icon-small { width: 48px; height: 48px; }
.icon-large { width: 80px; height: 80px; }

.icon:hover {
    transform: scale(1.1) rotate(5deg);
    filter: drop-shadow(0 4px 12px rgba(249, 111, 110, 0.4));
}

Creating New Icons

  • Match the aesthetic: Geometric, clean, minimal
  • Use 2px strokes: Consistent line weight across all icons
  • Rounded line caps: Softer, premium feel
  • 24×24 viewBox: Standard scalable format
  • Test at multiple sizes: 48px, 64px, 80px
  • No color mixing: One color per icon (coral, teal, white, or gradient)
  • Consider hover states: Scale, rotate, drop-shadow effects

⚠️ Critical Rule: No Emojis

Emojis introduce inconsistent colors, platform-dependent rendering, and break brand cohesion. Always use custom SVG icons in our brand colors. If you need a new icon concept, design it as SVG following these guidelines.
