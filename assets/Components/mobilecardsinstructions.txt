# Mobile Card Layout Fix Instructions

## Problem Diagnosis
Your cards are "fucked up" on mobile because:
1. **Desktop positioning values are too large for mobile screens** (50px+ left offsets)
2. **No mobile-specific card stack sizing** 
3. **Conflicting CSS rules** between desktop and mobile breakpoints
4. **Shuffle animations inherit desktop transform values**

## Step-by-Step Fix

### 1. Replace Your Mobile Media Query Section

**Find this section in your CSS** (around line 800+):
```css
@media (max-width: 768px) {
    .quick-tour-section { padding: 60px 0; }
    .card-stack { width: 350px; height: 550px; }
    .tour-card { width: 350px; height: 480px; }
    /* ... existing mobile rules */
}
```

**Replace it entirely with:**
```css
@media (max-width: 768px) {
    .quick-tour-section {
        padding: 60px 0;
    }

    .main-headline {
        font-size: 2.5rem;
    }

    .section-description {
        font-size: 1rem;
    }

    /* Mobile card stack - smaller and centered */
    .card-stack {
        width: 280px;
        height: 400px;
        margin: 0 auto 40px auto;
    }

    /* Mobile cards - smaller */
    .tour-card {
        width: 250px;
        height: 350px;
    }

    /* Mobile positioning - completely reset */
    .tour-card.position-1 {
        top: 0;
        left: 15px;
        z-index: 5;
        transform: rotate(-1deg);
    }

    .tour-card.position-2 {
        top: 8px;
        left: 12px;
        z-index: 4;
        transform: rotate(0.5deg);
    }

    .tour-card.position-3 {
        top: 16px;
        left: 9px;
        z-index: 3;
        transform: rotate(-0.5deg);
    }

    .tour-card.position-4 {
        top: 24px;
        left: 6px;
        z-index: 2;
        transform: rotate(1deg);
    }

    .tour-card.position-5 {
        top: 32px;
        left: 3px;
        z-index: 1;
        transform: rotate(-0.5deg);
    }

    /* Mobile flip states */
    .tour-card.position-1.flipped {
        transform: rotate(-1deg) rotateY(180deg);
    }

    .tour-card.position-2.flipped {
        transform: rotate(0.5deg) rotateY(180deg);
    }

    .tour-card.position-3.flipped {
        transform: rotate(-0.5deg) rotateY(180deg);
    }

    .tour-card.position-4.flipped {
        transform: rotate(1deg) rotateY(180deg);
    }

    .tour-card.position-5.flipped {
        transform: rotate(-0.5deg) rotateY(180deg);
    }

    /* Mobile card content adjustments */
    .card-front {
        padding: 20px;
    }

    .card-icon {
        font-size: 1.5rem;
        margin-bottom: 10px;
    }

    .card-content p {
        font-size: 0.85rem;
        margin-bottom: 15px;
    }

    .card-cta {
        padding: 10px 20px;
        font-size: 0.8rem;
    }
}
```

### 2. Add Mobile Shuffle Animation Rules

**Find your shuffling animation section** (around line 1000+) and **add this AFTER the desktop shuffling rules:**

```css
/* Mobile shuffling */
@media (max-width: 768px) {
    .shuffling .tour-card.position-1 { 
        transform: rotate(-1deg) translateY(-20px) scale(0.95); 
    }
    .shuffling .tour-card.position-2 { 
        transform: rotate(0.5deg) translateY(-16px) scale(0.95); 
    }
    .shuffling .tour-card.position-3 { 
        transform: rotate(-0.5deg) translateY(-12px) scale(0.95); 
    }
    .shuffling .tour-card.position-4 { 
        transform: rotate(1deg) translateY(-8px) scale(0.95); 
    }
    .shuffling .tour-card.position-5 { 
        transform: rotate(-0.5deg) translateY(-4px) scale(0.95); 
    }

    /* Mobile flip states during shuffling */
    .shuffling .tour-card.position-1.flipped { 
        transform: rotate(-1deg) translateY(-20px) scale(0.95) rotateY(180deg); 
    }
    .shuffling .tour-card.position-2.flipped { 
        transform: rotate(0.5deg) translateY(-16px) scale(0.95) rotateY(180deg); 
    }
    .shuffling .tour-card.position-3.flipped { 
        transform: rotate(-0.5deg) translateY(-12px) scale(0.95) rotateY(180deg); 
    }
    .shuffling .tour-card.position-4.flipped { 
        transform: rotate(1deg) translateY(-8px) scale(0.95) rotateY(180deg); 
    }
    .shuffling .tour-card.position-5.flipped { 
        transform: rotate(-0.5deg) translateY(-4px) scale(0.95) rotateY(180deg); 
    }
}
```

### 3. Add Extra Small Mobile Support

**Add this at the very end of your mobile media queries:**

```css
/* Extra small mobile */
@media (max-width: 480px) {
    .card-stack {
        width: 240px;
        height: 350px;
    }

    .tour-card {
        width: 220px;
        height: 320px;
    }

    .main-headline {
        font-size: 2rem;
    }
}
```

### 4. Ensure Desktop Rules Are Protected

**Make sure your desktop positioning rules are wrapped in a media query:**

```css
/* Desktop Card Positioning */
@media (min-width: 769px) {
    .tour-card.position-1 {
        top: 0;
        left: 50px;
        z-index: 5;
        transform: translateX(0) rotate(-2deg);
    }
    
    /* ... rest of your desktop rules ... */
}
```

## Key Changes Explained

1. **Card Stack Size**: Desktop `400px` → Mobile `280px` width
2. **Card Size**: Desktop `300x420px` → Mobile `250x350px` 
3. **Left Positioning**: Desktop `50px, 40px, 30px...` → Mobile `15px, 12px, 9px...`
4. **Top Spacing**: Desktop `15px` increments → Mobile `8px` increments
5. **Rotation**: Reduced angles for tighter mobile stacking

## Test Points

After making these changes, test at:
- **375px width** (iPhone SE)
- **414px width** (iPhone Pro Max)  
- **768px width** (iPad portrait)

The cards should now stack neatly within the mobile viewport without overflowing or looking cramped.

## Quick Verification

1. Open browser dev tools
2. Switch to mobile view (375px width)
3. Cards should be centered and stacked nicely
4. Shuffle button should work smoothly
5. No horizontal scrolling should occur

If you're still having issues after these changes, the problem might be in your card-flip JavaScript or conflicting CSS rules elsewhere in your stylesheet.
