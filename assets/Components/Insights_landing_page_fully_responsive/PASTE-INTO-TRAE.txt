## TASK: Fix Broken Tablet Navigation on Insights Page

### PROBLEM
The Insights page at `/insights/index.html` has NO navigation visible on tablet devices (768-1024px width). Desktop nav is hidden, mobile toggle shows but clicking does nothing because the mobile drawer is also hidden. This affects approximately 25% of visitors.

### SOLUTION
Implement a three-tier responsive breakpoint system:
- Desktop (>1024px): Horizontal navigation
- Tablet (768-1024px): Horizontal navigation (compact) ← Currently broken
- Mobile (≤768px): Slide-in drawer

### YOUR INSTRUCTIONS

Create 2 new files and modify 1 existing file as specified below. Follow exactly.
