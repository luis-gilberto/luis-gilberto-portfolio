Password Logic

Place JavaScript at the bottom of the body, just before </body>.

Do not place scripts in the head.

Hardcode the password constant.

const ACCESS_CODE = "YOUR_PASSWORD_HERE";

Behavior:

If password matches:

sessionStorage.setItem('nari-auth','true');
window.location.href = 'dashboard.html';

If password is incorrect:

• display the error message
• trigger shake animation on the input

Implementation rules:

• Do not use a <form> element
• Use button click handler
• Support Enter key submission on input field
• Authentication state stored only in sessionStorage

Authentication Guard

if (sessionStorage.getItem('nari-auth') !== 'true') {
