## How to Delete Duplicates

### Step 1: Open Your HTML
Open `index.html` in a code editor (VS Code, Sublime, etc.)

### Step 2: Find Duplicates
Press `Cmd + F` (Mac) or `Ctrl + F` (Windows) and search for:
```
.hub-reveal-system
```

### Step 3: Identify the Keeper
The **first one you find** (in the `<head>`) is usually the keeper. It should have:
- `background: transparent`
- `backdrop-filter: none`
- Clean, organized comments

### Step 4: Delete the Others
For each subsequent `.hub-reveal-system` block:
1. Select the entire CSS block (from the opening `{` to closing `}`)
2. Delete it
3. Make sure you delete ALL related rules (`.energy-burst`, `.service-image`, etc.)

### Step 5: Increase Opacity (Temporary Fix)
In the ONE remaining CSS block, find these four rules:
```css
.service-advisory.reveal { opacity: 0.15; }
.service-imc.reveal { opacity: 0.15; }
.service-scope.reveal { opacity: 0.15; }
.service-strategy.reveal { opacity: 0.15; }
```

Change ALL to:
```css
.service-advisory.reveal { opacity: 0.85; }
.service-imc.reveal { opacity: 0.85; }
.service-scope.reveal { opacity: 0.85; }
.service-strategy.reveal { opacity: 0.85; }
```

This will make them MUCH more visible for testing. Once confirmed working, you can dial it back to 0.15 for the subtle ambient effect.
