TROUBLESHOOTING:
----------------
If something looks wrong:

1. Make sure you deleted ALL the old icon section code
2. Check that your main stylesheet still has the core CSS variables defined:
   --coral, --teal, --glass-bg, --glass-border, --glass-blur
3. Verify the scroll reveal JavaScript is still at the bottom of your page
4. Clear your browser cache (Cmd+Shift+R on Mac, Ctrl+Shift+R on Windows)
5. Check browser console for any errors (F12 → Console tab)
