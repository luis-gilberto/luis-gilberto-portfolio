# Move at the Speed of What Matters
*A Personal Reset*

## Overview
An interactive 4-page article exploring the journey from corporate burnout to creative renaissance through the lens of slowing down in an AI-accelerated world.

## Features
- Interactive paginated reading experience
- Embedded transition timeline with hover effects
- Complete tool stack showcase
- Mobile responsive design
- Professional typography with custom fonts

## Publication Date
August 8, 2025

## Reading Time
Approximately 8 minutes

## Topics
- Career transition
- AI and productivity
- Creative process
- Personal growth
- Work-life balance

## Technical Details
- Pure HTML/CSS/JavaScript
- No external dependencies except fonts and icons
- Chart.js for data visualization
- Font Awesome for icons
- Responsive design for all devices

## Tools Featured
- **Design**: Framer, Canva Pro
- **AI Assistants**: ChatGPT, Copilot, GenSpark, Claude
- **Development**: Trae, GitHub
- **Creative**: 21st.dev, intuition, YouTube exploration
