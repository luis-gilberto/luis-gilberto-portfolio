PART 6: OPTIONAL THEME PERSISTENCE HOOK
========================================================

Only add this if it is not already included elsewhere on Insights pages.

Right before </body>, ADD:

<script>
  window.setTheme = function(theme) {
    if (theme !== 'light' && theme !== 'dark') return;
    document.documentElement.setAttribute('data-theme', theme);
    try { localStorage.setItem('lg_theme', theme); } catch(e) {}
  };
  (function initTheme() {
    try {
      const saved = localStorage.getItem('lg_theme');
      if (saved === 'light' || saved === 'dark') {
        document.documentElement.setAttribute('data-theme', saved);
      }
    } catch(e) {}
  })();
</script>
