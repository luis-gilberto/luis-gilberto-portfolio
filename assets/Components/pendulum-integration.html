Pendulum Drift — Integration Guide

Three code blocks to paste into your brand page. Takes about 5 minutes. Frames go in /assets/images/pendulum/ and that's it.

Before You Start

STEP 0 / FILE PREP
Copy your frames to the server
Rename your 12 pendulum images to frame-01.png through frame-12.png (zero-padded). Copy the folder to your server at: /assets/images/pendulum/

⚠ The animation works exactly as described even if you use different filenames — just update the src attributes in Block 2 to match your actual file names.

Block 3 — JavaScript replace video autoplay line in your <script> block

Find this line at the bottom of your existing <script> block and remove it:

document.getElementById('pendulumVideo')?.play().catch(() => {});

Then paste Block 3 in its place (still inside the IIFE closing })();):

// ═══════════════════════════════════════════════════════
// PENDULUM DRIFT PLAYER
// 12 PNG frames — forward 1→12, reverse 12→1, infinite
// Hover pauses. prefers-reduced-motion → static frame 7.
// ═══════════════════════════════════════════════════════
(function initPendulum() {
  const TOTAL    = 12;
  const FRAME_MS = 720;   // ms per frame (lower = faster)
  const PAUSE_MS = 900;   // pause at each end before reversing

  // Phase labels matching the animation brief
  const PHASES = {
    1: 'origin',  2: 'origin',
    3: 'extract', 4: 'extract',
    5: 'drift',   6: 'fusion',
    7: 'mark',    8: 'mark',
    9: 'depth',  10: 'depth',
   11: 'shift',  12: 'shift'
  };

  const frames     = Array.from({ length: TOTAL }, (_, i) => document.getElementById('pf-' + (i + 1)));
  const dots       = Array.from(document.querySelectorAll('#pendulumProgress .pendulum-dot'));
  const dirLabel   = document.getElementById('pendulumDir');
  const phaseLabel = document.getElementById('pendulumPhase');
  const track      = document.getElementById('pendulumTrack');

  if (!frames[0]) return; // guard: frames not in DOM

  // Respect prefers-reduced-motion — show clean monogram statically
  if (window.matchMedia('(prefers-reduced-motion: reduce)').matches) {
    frames.forEach((f, i) => f.classList.toggle('active', i === 6));
    dots.forEach((d, i)   => d.classList.toggle('active', i === 6));
    if (phaseLabel) phaseLabel.textContent = 'mark';
    return;
  }

  let current   = 0;    // 0-indexed current frame
  let direction = 1;    // 1 = forward, -1 = reverse
  let timer     = null;
  let paused    = false;

  function showFrame(idx) {
    frames.forEach((f, i) => f.classList.toggle('active', i === idx));
    dots.forEach((d, i)   => d.classList.toggle('active', i === idx));
    if (dirLabel)   dirLabel.textContent   = direction === 1 ? '→' : '←';
    if (phaseLabel) phaseLabel.textContent = PHASES[idx + 1] || '';
  }

  function step() {
    if (paused) return;

    const next = current + direction;

    if (next >= TOTAL || next < 0) {
      // Hit an end — flip direction, pause before continuing
      direction *= -1;
      if (dirLabel) dirLabel.textContent = direction === 1 ? '→' : '←';
      timer = setTimeout(step, PAUSE_MS);
      return;
    }

    current = next;
    showFrame(current);

    // Organic easing: slightly slower at origin/peak, faster through middle
    const progress = current / (TOTAL - 1);
    const easing   = 0.7 + 0.6 * Math.sin(Math.PI * progress);
    timer = setTimeout(step, FRAME_MS / easing);
  }

  // Init + start after page settle
  showFrame(0);
  timer = setTimeout(step, 1400);

  // Pause on hover — lets user read channel node cards
  if (track) {
    track.addEventListener('mouseenter', () => {
      paused = true;
      clearTimeout(timer);
    });
    track.addEventListener('mouseleave', () => {
      paused = false;
      timer = setTimeout(step, FRAME_MS);
    });
  }
})();

Tuning Reference optional adjustments

TIMING
Adjust animation speed
In Block 3, change FRAME_MS = 720 to control base speed. Lower = faster. Recommended range: 500–1200. Change PAUSE_MS = 900 to control how long it pauses at the name (frame 1) and peak mark (frame 12) before reversing.
CROSSFADE
Adjust the blend between frames
In Block 1, change transition: opacity 0.8s ease-in-out on .pendulum-frame. Shorter = snappier cuts. Longer = dreamier dissolves. Keep it under the FRAME_MS value or frames will overlap awkwardly.
HEIGHT
Adjust track height
In Block 1, change height: 480px on .pendulum-track. Desktop recommendation: 400–560px depending on your frame aspect ratio.

✓ The animation pauses automatically when the user hovers over the track, giving them time to interact with the channel node cards. It resumes when they move away.

✓ If a frame fails to load, it simply shows as transparent — the animation continues without breaking. No error states needed.
