Cómo se sirve cada archivo

Transformación por defecto

Todo asset que se inserte en web va con f_auto,q_auto. El botón Copiar optimizada de cada tarjeta ya lo aplica.

Anchos recomendados

  • Nav y firma de correo: w_240
  • Tarjeta de caso o pie de página: w_480
  • Hero o presentación: w_1200

Reglas de uso

  • Monograma solo: cuando el nombre LG Studio ya aparece cerca en texto.
  • Lockup horizontal: cabeceras, firmas, barras de navegación.
  • Lockup apilado y lockup con firma: portadas, aperturas, formatos cuadrados.
  • Firma READ / DIRECT / BUILD: es firma de la practica, no tagline obligatorio. El monograma y el logotipo pueden ir solos. Nunca bajo 160 px de ancho.
  • Área de respiro mínima: la altura de la contraforma del monograma.
  • Versión blanca sobre Superficie Tinta o fotografía oscura. Nunca blanco sobre Superficie Papel.

Cómo agregar un asset

Una línea, un archivo

Este documento se mantiene solo. Abra el archivo, busque el arreglo ASSETS cerca del final y agregue un objeto nuevo. El índice, los filtros, los contadores y la matriz de cobertura se actualizan solos. Los campos de texto llevan versión en español y en inglés.

{
  id: "LGS-011",
  nombre: { es: "Patrón de fondo", en: "Background pattern" },
  publicId: "LG_Studio_pattern_mono_ab12cd",
  version: "v1786150680",
  formato: "png",
  dim: "1536 x 1024",
  categoria: "sistema",     // monogram wordmark lockup cobranding sistema
  tier: null,                // primary secondary environmental extension archive
  familia: null,             // alimenta la matriz, null si no aplica
  color: null,               // blanco negro null
  fondo: "claro",            // claro oscuro transparente
  uso: { es: "...", en: "..." },
  estado: "activo",          // activo revisar archivo
  nota: { es: "", en: "" }
}
