Icon Visual Regression Tests

This harness verifies that converted icons have fully transparent backgrounds, preserve dimensions/aspect ratios, and render consistently in hover, active, and disabled states.

Technical notes
  • Transparency check samples corner pixels via canvas to verify alpha channel is 0.
  • Dimensions reported are the intrinsic natural size (PNG) and rendered size in the tester.
  • State rendering previews apply typical UI filters/styles for hover/active/disabled.
