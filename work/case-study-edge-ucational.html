Vision & Opportunity

Making Power Feel Effortless

How might we make Edge's most advanced features feel effortless and inviting? We created the Edge-ucational series — a campaign of friendly, bite-sized videos that helped users not only understand Edge, but love it.

"We turned product features into real-life storytelling moments that educated, delighted, and empowered."

Role
Strategy Lead
Partner
Buck
Challenge
Edge's most powerful features were going undiscovered — not because users didn't want them, but because nothing made the value tangible.
Approach
Lifestyle-led storytelling over feature documentation.
The Approach

Translating Complexity

01
User Analysis

Identified friction points and mapped user mindsets to create content that solved specific anxieties — not a feature list, but a fear inventory.

02
The Framework

Grouped capabilities into lifestyle themes — Shopping, Safety, Focus — rather than technical buckets. Users don't think in menus. We stopped writing for menus.

03
Visual Language

Created a "Deconstructed UI" aesthetic that removed clutter to focus entirely on the user payoff — what you feel, not what you click.
