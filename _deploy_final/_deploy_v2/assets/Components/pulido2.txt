# Full-Viewport Snap Scrolling Implementation Guide

## Overview
Implement full-viewport sections with snap scrolling behavior, remove decorative circles from section dividers, and update section divider labels to be less redundant.

---

## CSS Changes

### 1. Update Smooth Scrolling System (Line ~27)
**FIND:**
```css
/* Smooth Scrolling System */
html {
    scroll-snap-type: y proximity;
    scroll-behavior: smooth;
}
```

**REPLACE WITH:**
```css
/* Full-Viewport Snap Scrolling System */
html {
    scroll-snap-type: y mandatory;
    scroll-behavior: smooth;
    overflow-y: scroll;
}

/* Each major section becomes a snap point */
section {
    scroll-snap-align: start;
    scroll-snap-stop: normal;
}
```

## Testing & Verification

After implementing all changes, verify the following behavior:

1. **Snap Scrolling**: When you scroll with mouse wheel or trackpad, the page should snap cleanly to the next section
2. **Full Viewport**: Each section should fill the entire viewport height (100vh)
3. **No Circles**: Section dividers should only show a horizontal gradient line with text, no circular overlays
4. **Centered Content**: All content in each section should be vertically centered
5. **Better Labels**: Section divider labels should be:
   - "What I Offer" (before Services)
   - "Flexible Engagement" (before Investment)
   - "Microsoft Legacy" (before Legacy section)

---

## Expected Result

- Each section fills the entire viewport
- Smooth snap-to-section scrolling behavior
- Clean, minimal section dividers without decorative circles
- No redundant section names
- Professional, magazine-style scrolling experience
- Content properly centered in each viewport

---

## Notes

- The `scroll-snap-type: y mandatory` creates the snap-to-section behavior
- The `height: 100vh` on sections ensures full-viewport coverage
- The reduced padding (`5vh`) maintains spacing while allowing content to breathe
- Section dividers are now minimal (`10vh` height) to act as visual breaks without wasting space
