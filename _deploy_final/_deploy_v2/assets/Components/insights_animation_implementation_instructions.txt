================================================================================
TECHNICAL DETAILS & NOTES
================================================================================

WHY USE <picture> ELEMENT:
- Progressive enhancement for modern browsers
- Automatic format selection based on browser support
- No JavaScript required for fallback logic
- Better performance without sacrificing compatibility

HOW BROWSER SELECTION WORKS:
1. Browser checks <source> elements in order
2. If browser supports WebP → loads .webp file
3. If browser doesn't support WebP → falls back to <img> src (JPG)
4. Happens automatically, no manual intervention needed

PERFORMANCE BENEFITS:
- WebP files are ~50% smaller than equivalent quality JPG
- Faster page load times
- Reduced bandwidth usage
- Better Core Web Vitals scores (LCP)

ACCESSIBILITY:
- Alt text on <img> element provides proper description
- Works with screen readers
- Keyboard navigation unaffected

CACHING:
- Both WebP and JPG files can be cached by CDN
- First visit loads appropriate format
- Subsequent visits load from cache

loading="lazy" ATTRIBUTE:
- Defers loading of still image until needed
- Improves initial page load performance
- Browser native feature (no JS required)
