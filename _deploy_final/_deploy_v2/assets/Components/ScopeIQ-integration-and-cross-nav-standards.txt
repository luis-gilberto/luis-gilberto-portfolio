4. STRATEGIC PLACEMENT GUIDELINES
ScopeIQ Integration Strategy
Entry Points: Always offer ScopeIQ as the "quick start" option alongside full service exploration
Service Connections: Link specific ScopeIQ modules to corresponding full services
Process Integration: Position ScopeIQ as the natural first step in the "Discover" phase
Conversion Funnel: Use assessment completion as qualification for deeper engagement
Cross-Navigation Best Practices
Always include all four pages in the cross-nav
Maintain consistent icon styles and naming
Ensure the active page is clearly indicated
Test navigation flow between all pages
Use descriptive aria-labels for accessibility
URL Structure Recommendations
/scopeiq - ScopeIQ Assessment Wizard
/imc-services - Main IMC Services Hub (this page)
/brand - Brand-focused services page
/engagement-toolkit - Luis's personal toolkit page
