4. ANIMATION SPEEDS:

   - SVG data URLs work in all modern browsers
   - -webkit-mask-image included for Safari support
   - pointer-events: none ensures no interaction blocking

   ✓ Hero text remains readable
   ✓ No orbital on Bridge section
