STEP 6: ADD JAVASCRIPT
================================================================================

Place this JavaScript just before the closing </body> tag, AFTER the footer
HTML:

```html
<!-- JAVASCRIPT -->
<script>
    // =========================================
    // Mobile Menu Toggle
    // =========================================
    const mobileToggle = document.getElementById('mobileToggle');
    const headerNav = document.getElementById('headerNav');

    if (mobileToggle && headerNav) {
        mobileToggle.addEventListener('click', () => {
            headerNav.classList.toggle('mobile-active');
            const isActive = headerNav.classList.contains('mobile-active');
            mobileToggle.querySelector('span').textContent = isActive ? '✕' : '☰';
        });
    }

    // =========================================
    // Header Scroll Effect
    // =========================================
    const hubHeader = document.getElementById('hubHeader');

    if (hubHeader) {
        window.addEventListener('scroll', () => {
            const currentScroll = window.pageYOffset;
            
            if (currentScroll > 50) {
                hubHeader.classList.add('scrolled');
            } else {
                hubHeader.classList.remove('scrolled');
            }
        });
    }

    // =========================================
    // Smooth Scrolling for Internal Links
    // =========================================
    document.querySelectorAll('a[href^="#"]').forEach(anchor => {
        anchor.addEventListener('click', function (e) {
            e.preventDefault();
            const target = document.querySelector(this.getAttribute('href'));
            if (target) {
                target.scrollIntoView({
                    behavior: 'smooth',
                    block: 'start'
                });
            }
        });
    });
</script>
```

STEP 7: ADJUST MAIN CONTENT WRAPPER
================================================================================

Your main content needs to be offset for the fixed header. Wrap all your page
content (everything between header and footer) in a container with proper
padding:

OPTION A: Add this CSS to your existing main content wrapper:
```css
.your-main-content-class {
  padding-top: 80px; /* Desktop header height */
}

@media (max-width: 768px) {
  .your-main-content-class {
    padding-top: 70px; /* Mobile header height */
  }
}
```

OPTION B: If you don't have a main content wrapper, create one:
```html
<header class="hub-header">...</header>

<div class="main-content-wrapper" style="padding-top: 80px;">
  <!-- All your page content goes here -->
</div>

<footer class="hub-footer">...</footer>
```

And add this CSS:
```css
.main-content-wrapper {
  padding-top: 80px;
}

@media (max-width: 768px) {
  .main-content-wrapper {
    padding-top: 70px;
  }
}
```

TROUBLESHOOTING
================================================================================

ISSUE: Header covers page content
FIX: Add padding-top to your main content wrapper (Step 7)

ISSUE: Navigation icons don't display
FIX: Verify asset paths in Step 9

ISSUE: Active state doesn't show
FIX: Ensure "active" class is on correct nav-item for that page (Step 8)

ISSUE: Mobile menu doesn't work
FIX: Verify JavaScript is placed correctly (Step 6)

ISSUE: Styles conflict with existing CSS
FIX: Check that CSS variables are defined before other rules (Step 1)

ISSUE: Header doesn't stick to top
FIX: Verify .hub-header has position: fixed

ISSUE: Footer spacing is off
FIX: Ensure footer has margin-top: 6rem in CSS
