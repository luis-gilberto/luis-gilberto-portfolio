 Editorial Illustration Treatment Implementation Guide
## For: Proof of Life Article | insights/proof-of-life.html

---

## OBJECTIVE
Transform the decorative break images from "slapped on" stock treatments into sophisticated editorial illustrations that function as intentional visual stamps throughout the narrative. The illustrations should feel like they were commissioned specifically for this piece, with varying scales and placements that create visual rhythm and reinforce the article's themes.

---

## DESIGN PHILOSOPHY
Think New Yorker editorial illustration meets Caracas-meets-Cascadia aesthetic:
- **Intentional placement** over uniform centering
- **Varying scales** over consistency
- **Breathing room** over decoration
- **Visual punctuation** over page breaks
- **Human fingerprints** as editorial marks in the margins

---

## PLACEMENT STRATEGY

**The four fingerprints should appear:**

1. **After opening "I call it proof of life" section** → `full-width with-divider`

2. **End of "Autopilot Problem" section** → `align-right`

## RATIONALE

This treatment transforms the fingerprint illustrations from decorative interruptions into **editorial punctuation** — they become part of the essay's argument about human presence in creative work. Each illustration:

- **Appears at the right narrative moment** to reinforce the theme
- **Varies in scale** to create visual rhythm (like musical dynamics)
- **Uses asymmetry strategically** to break monotony
- **Feels commissioned** rather than templated
- **Demonstrates the article's thesis** through its own intentional design

The result: illustrations that feel like they have fingerprints on them — evidence that someone was awake at the wheel.

### JavaScript Implementation

**Replace existing mobile navigation JavaScript with:**

```javascript
document.addEventListener("DOMContentLoaded", function () {
  const header = document.querySelector(".lg-site-header");
  const toggle = document.querySelector(".lg-nav-toggle");
  const closeBtn = document.querySelector(".lg-nav-close");
  const nav = document.querySelector(".lg-main-nav");
  const overlay = document.querySelector(".lg-nav-overlay");

  if (!header) return;

  // Scroll shadow effect
  function updateHeaderShadow() {
    if (window.scrollY > 4) {
      header.classList.add("is-scrolled");
    } else {
      header.classList.remove("is-scrolled");
    }
  }

  updateHeaderShadow();
  window.addEventListener("scroll", updateHeaderShadow);

  // Function to open menu
  function openMenu() {
    header.classList.add("is-open");
    toggle.setAttribute("aria-expanded", "true");
    nav.setAttribute("aria-hidden", "false");
    document.body.style.overflow = "hidden";
  }

  // Function to close menu
  function closeMenu() {
    header.classList.remove("is-open");
    toggle.setAttribute("aria-expanded", "false");
    nav.setAttribute("aria-hidden", "true");
    document.body.style.overflow = "auto";
  }

  // Toggle button click
  if (toggle) {
    toggle.addEventListener("click", function () {
      const isOpen = header.classList.contains("is-open");
      if (isOpen) {
        closeMenu();
      } else {
        openMenu();
      }
    });
  }

  // Close button click (X inside drawer)
  if (closeBtn) {
    closeBtn.addEventListener("click", function () {
      closeMenu();
    });
  }

  // Click outside to close (overlay click)
  if (overlay) {
    overlay.addEventListener("click", function () {
      closeMenu();
    });
  }

  // Close on escape key
  document.addEventListener("keydown", function (e) {
    if (e.key === "Escape" && header.classList.contains("is-open")) {
      closeMenu();
    }
  });
});
```

### Design Specifications

**Dimensions:**
- Button size: 48px × 48px
- Line width: 20px
- Line thickness: 2px
- Border radius: 12px
- Line spacing: 6px between each line

**Colors:**
- Closed state background: `rgba(0, 0, 0, 0.02)`
- Closed state border: `rgba(0, 0, 0, 0.08)`
- Line color (closed): `var(--black)`
- Open state background: `rgba(255, 107, 88, 0.08)` (coral tint)
- Open state border: `rgba(255, 107, 88, 0.2)`
- Line color (open): `var(--coral)` (#FF6B58)

**Effects:**
- Backdrop blur: 12px
- Layered shadows (outer + inset) for depth
- Easing: `cubic-bezier(0.4, 0, 0.2, 1)` (smooth, premium)
- Transition duration: 0.3s
