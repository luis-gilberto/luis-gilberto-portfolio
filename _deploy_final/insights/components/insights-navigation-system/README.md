# Insights Navigation System
This package provides a mobile/tablet drawer for the Insights section that filters latest articles (last 90 days), organizes series (Building Series with nested sub-groups, Use Cases, Reflections), and aggregates topics.

Contents:
- css/insights-navigation.css
- js/insights-navigation.js
- data/articles-metadata.json
- docs/README.md
- docs/STRUCTURE.md
- insights-drawer-example.html

Deploy CSS to `/insights/assets/css/insights-navigation.css`, JS to `/insights/assets/js/insights-navigation.js`, JSON to `/insights/data/articles-metadata.json`.
