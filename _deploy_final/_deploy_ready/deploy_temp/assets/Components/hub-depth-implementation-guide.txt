================================================================================
TECHNICAL NOTES
================================================================================

WHY THIS WORKS (The Physics):

1. FIXED POSITIONING creates true parallax:
   - Shapes stay in viewport while content scrolls
   - Creates automatic depth separation

2. LOW OPACITY (0.04-0.12) mimics atmospheric perspective:
   - Distant objects appear fainter in real life
   - Far layer at 0.04 = barely visible ghost
   - Front layer at 0.12 = present but not dominant

3. BLUR GRADIENT simulates depth of field:
   - Far objects are out of focus (3px blur)
   - Near objects are sharper (0.5px blur)
   - Matches how cameras/eyes work

4. Z-INDEX SEPARATION prevents overlap:
   - Shapes: z-index 0-3 (background plane)
   - Content: z-index 10+ (foreground plane)
   - Header: z-index 1000 (UI plane)

5. BACKDROP-FILTER on cards creates glass effect:
   - Blurs shapes behind cards
   - Enhances depth perception
   - Separates layers visually

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: Shapes appear in front of cards
SOLUTION: 
- Check card z-index is 20+ (must be higher than shape z-index 0-3)
- Verify .floating-shapes has z-index: 0
- Ensure cards have position: relative

PROBLEM: Shapes not visible at all
SOLUTION:
- Check opacity values (should be 0.04-0.12, not 0)
- Verify SVG paths are correct
- Check if shapes are off-screen (adjust top/left/right/bottom)
- Inspect with DevTools (look for display: none or visibility: hidden)

PROBLEM: Shapes don't stay fixed on scroll
SOLUTION:
- Verify .floating-shapes has position: fixed (NOT absolute)
- Check for parent containers with transform properties (breaks fixed)
- Remove any overflow: hidden on parent elements

PROBLEM: Animation is choppy
SOLUTION:
- Check will-change: transform is present
- Verify GPU acceleration (force with transform: translateZ(0))
- Reduce animation complexity (remove scale changes)
- Increase animation duration (less frequent updates)

PROBLEM: Shapes invisible on mobile
SOLUTION:
- Check media query opacity values (should be higher on mobile)
- Verify transform: scale(0.85) not making shapes too small
- Adjust positioning for mobile viewport

PROBLEM: Blur not working
SOLUTION:
- Check browser support (filter: blur requires modern browser)
- Try -webkit-filter: blur() for Safari
- Use backdrop-filter on parent if filter fails
