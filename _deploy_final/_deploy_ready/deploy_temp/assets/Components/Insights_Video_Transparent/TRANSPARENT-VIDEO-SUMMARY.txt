===========================================
KEY TECHNICAL DETAILS
===========================================

FORMAT: WebM VP9 with alpha channel
- Only format that supports web video transparency
- 95%+ browser support (all modern browsers)
- MP4 doesn't support alpha (why we can't use it)

ALPHA CHANNEL: ALPHA_MODE=1 metadata flag
- Tells browsers to render transparency
- No additional CSS tricks needed
- Hardware accelerated

OPTIMIZATION:
- Progressive loading (streaming)
- Poster images for instant load
- 8 seconds, 24fps, 720x720
- Smooth seamless loop

SIZE: ~4.1 MB total package
- Acceptable for premium hero animation
- Loads progressively
- Mobile optimized
