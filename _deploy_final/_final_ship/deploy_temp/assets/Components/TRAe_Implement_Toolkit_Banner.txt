====================================================
4) JS — OPTIONAL CHIP VISIBILITY VIA ?source
====================================================
Show the "IMC Services" chip only when traffic comes from the hub using a `?source=imcservices` param.
If you like the chip always visible, SKIP this step.

Add this small script at the bottom of the Toolkit page (or your main bundle):

<script>
  (function() {
    try {
      const params = new URLSearchParams(window.location.search);
      const chip = document.querySelector('.imc-chip');
      if (!chip) return;
      const show = params.get('source') === 'imcservices';
      chip.style.display = show ? 'inline-block' : 'none';
    } catch (e) { /* fail safe: do nothing */ }
  })();
</script>
