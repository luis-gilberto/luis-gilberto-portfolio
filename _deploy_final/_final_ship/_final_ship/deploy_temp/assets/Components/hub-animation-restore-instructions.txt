THE HUB LOADING ANIMATION - SURGICAL RESTORATION GUIDE
================================================================================

OVERVIEW:
The Hub homepage (TheHub/index.html) previously had a loading animation that 
played when users accessed the page via direct URL entry (luis-gilberto.com/TheHub 
or luis-gilberto.com/workwithme). This animation was lost during a rebuild.

This document contains 4 surgical fixes to restore the animation functionality.

ANIMATION BEHAVIOR:
✅ Animation PLAYS when:
   - User types URL directly in browser
   - User accesses via bookmark
   - User comes from external site (Google, social media, etc.)

❌ Animation SKIPS when:
   - User clicks any internal link from luis-gilberto.com
   - User navigates via header/footer links
   - User uses browser back/forward buttons

REQUIRED FILES (already confirmed to exist):
- /TheHub/assets/components/hub-animation/hub-loader.min.js
- /TheHub/assets/components/hub-animation/coral_laser_line.mp4

FIX #4: ADD ANIMATION INITIALIZATION SCRIPT
================================================================================

LOCATION: Right before the closing </body> tag, after all existing scripts

ACTION: Add this complete script block as the LAST thing before </body>

CODE TO ADD:
--------------------------------------------------------------------------------
<!-- Hub Loading Animation Initialization -->
<script>
  document.addEventListener('DOMContentLoaded', function() {
    const referrer = document.referrer;
    
    // Check if user came from internal navigation (any link from luis-gilberto.com)
    const isInternalNavigation = referrer && referrer.includes('luis-gilberto.com');
    
    // Check if user recently navigated internally (prevents animation on back/forward)
    const hasInternalNavigationFlag = sessionStorage.getItem('hubNavigated') === 'true';
    
    // Show animation ONLY when:
    // - User typed URL directly (no referrer)
    // - User came from external site (referrer exists but not luis-gilberto.com)
    // - User came from bookmark
    // SKIP animation when:
    // - User clicked any internal link from the site
    const shouldShowAnimation = !isInternalNavigation && !hasInternalNavigationFlag;
    
    if (shouldShowAnimation) {
      // Clear navigation flag for fresh direct access
      sessionStorage.removeItem('hubNavigated');
      
      // Create and show the animation
      const loader = HubLoader.create({
        videoUrl: './assets/components/hub-animation/coral_laser_line.mp4',
        duration: 12000,
        autoStart: true,
        showProgress: false,
        skipOnClick: true,
        onComplete: function() {
          // Logo collapse animation
          const logoOverlay = document.querySelector('.hub-logo-overlay');
          if (logoOverlay) {
            logoOverlay.classList.add('hub-logo-collapse');
          }
          
          // Show main content
          setTimeout(() => {
            const mainContent = document.getElementById('main-content');
            if (mainContent) {
              mainContent.style.display = 'block';
            }
            
            // Nav logo pulse effect
            setTimeout(() => {
              const navLogo = document.querySelector('.hub-nav-logo-img');
              if (navLogo) {
                navLogo.classList.add('nav-logo-attract');
              }
            }, 500);
            
            // Reveal elements
            const revealElements = document.querySelectorAll('.reveal');
            revealElements.forEach(el => {
              if (el.getBoundingClientRect().top < window.innerHeight) {
                el.classList.add('in');
              }
            });
          }, 2000);
        }
      });
      
    } else {
      // User navigated internally - skip animation entirely
      sessionStorage.setItem('hubNavigated', 'true');
      
      // Show content immediately
      const mainContent = document.getElementById('main-content');
      if (mainContent) {
        mainContent.style.display = 'block';
      }
      
      // Immediately reveal all elements
      const revealElements = document.querySelectorAll('.reveal');
      revealElements.forEach(el => {
        el.classList.add('in');
      });
      
      // Hide any loading overlays
      const logoOverlay = document.querySelector('.hub-logo-overlay');
      if (logoOverlay) {
        logoOverlay.style.display = 'none';
      }
    }
  });
  
  // Track when user clicks internal links
  document.addEventListener('click', function(e) {
    const link = e.target.closest('a');
    // If clicking any internal link, mark as internal navigation
    if (link && link.href && link.href.includes('luis-gilberto.com')) {
      sessionStorage.setItem('hubNavigated', 'true');
    }
  });
</script>

================================================================================
TROUBLESHOOTING
================================================================================

If animation doesn't play:
1. Check browser console for JavaScript errors
2. Verify hub-loader.min.js loads successfully (Network tab)
3. Verify coral_laser_line.mp4 loads successfully (Network tab)
4. Confirm #main-content div is properly wrapped around all body content
5. Clear browser cache and sessionStorage

If animation plays when it shouldn't:
1. Clear sessionStorage in browser dev tools
2. Verify the click event listener is properly tracking internal links
3. Check that referrer detection is working (console.log the referrer)

NOTES
================================================================================

- Users can skip the animation by clicking anywhere during playback
- sessionStorage is used to remember internal navigation (clears on browser close)
- The animation only affects the initial page load experience
