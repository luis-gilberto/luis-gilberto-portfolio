Troubleshooting Common Issues

CSS Conflicts

Problem: Styles not applying or looking broken

Solution: Check if existing CSS has higher specificity. Add !important to conflicting properties or increase specificity by adding parent selectors.

Navigation Breaking

Problem: Navigation menu looks different or broken

Solution: The CSS file explicitly preserves navigation. If issues occur, check for accidental class additions to nav elements.

Footer Issues

Problem: Footer styling changes unexpectedly

Solution: Footer styles are preserved in the CSS. Avoid adding enhancement classes to footer elements.

Mobile Responsiveness

Problem: Layout breaks on mobile

Solution: The CSS includes mobile breakpoints. Test on actual devices, not just browser resize.
