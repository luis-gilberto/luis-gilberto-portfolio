Hero Section: Technical Specifications

Desktop Layout (1024px+)

<section class="hero-section">
  <div class="hero-content">
    <h1 class="hero-headline">
      Creative Leadership
      Through Innovation
    </h1>
    
    <div class="hero-image">
      <img src="luis-portrait.jpg" alt="Luis Gilberto">
    </div>
    
    <h2 class="name-display">LUIS GILBERTO</h2>
    <p class="value-prop">Transforming brand challenges into breakthrough opportunities</p>
    
    <div class="cta-buttons">
      <button class="btn-primary">Explore Partnerships</button>
      <button class="btn-secondary">View Case Studies</button>
    </div>
  </div>
</section>

Typography Scale

  • Hero Headline: 56px, font-weight: 700, line-height: 1.1
  • Name Display: 32px, font-weight: 600, letter-spacing: 0.05em
  • Value Prop: 18px, font-weight: 400, line-height: 1.6

Spacing & Layout

  • Hero Padding: 120px top, 80px bottom
  • Element Spacing: 40px between major elements
  • Button Gap: 24px between CTAs
  • Max Width: 1200px centered

Mobile Layout (768px-)

/* Mobile-First Approach */
.hero-headline {
  font-size: 32px;
  line-height: 1.1;
  margin-bottom: 32px;
}

.hero-image {
  width: 100%;
  max-width: 300px;
  margin: 0 auto 24px;
}

.name-display {
  font-size: 24px;
  text-align: center;
  margin-bottom: 16px;
}

.cta-buttons {
  flex-direction: column;
  gap: 16px;
  width: 100%;
}

.btn-primary, .btn-secondary {
  width: 100%;
  height: 52px;
  min-width: 44px; /* Touch target */
}

Mobile Optimizations

  • Touch Targets: Minimum 44px height for all interactive elements
  • Image Aspect: 4:5 portrait crop for better mobile viewing
  • Stacked Layout: All elements vertically centered
  • Side Margins: 24px minimum for thumb-friendly navigation

Performance Considerations

  • Image Optimization: WebP format with JPEG fallback
  • Loading Priority: Hero image should be preloaded
  • Animation Performance: Use transform instead of changing layout properties
