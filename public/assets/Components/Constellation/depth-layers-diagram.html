Depth Perception

Created through size variation (26-88px), opacity gradient (0.06-0.22), blur levels (0-2px), and animation speed (32-50s)

Color Balance

4 coral shapes (warm, energetic) and 4 teal shapes (cool, analytical) distributed evenly across all layers for visual harmony

Layering Magic

Badge and stats sit at z-index: 2 (same as front shapes), allowing some shapes to appear behind UI elements while others remain in front

Performance

GPU-accelerated animations using transform and opacity only, with will-change hints and reduced motion support for accessibility
