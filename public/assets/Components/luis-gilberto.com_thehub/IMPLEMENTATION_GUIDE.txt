THE HUB - PREMIUM DESIGN IMPLEMENTATION GUIDE
==============================================

OVERVIEW
--------
This package contains a premium, award-winning design for The Hub landing page.
It includes modern animations, ambient effects, and sophisticated interactions.

WHAT'S INCLUDED
---------------
1. main-sections.html - Core page sections (Hero, Philosophy, Services, Expertise, CTA)
2. premium-styles.css - All styling including animations and effects
3. premium-interactions.js - JavaScript for animations and interactions
4. IMPLEMENTATION_GUIDE.txt - This file

IMPLEMENTATION STEPS
--------------------

STEP 1: Add the CSS
-------------------
Add this line in your <head> section AFTER your existing styles:
<link rel="stylesheet" href="./css/premium-styles.css">

STEP 2: Add the HTML Sections
------------------------------
Copy the content from main-sections.html and paste it into your page body
where you want the content to appear (between your existing header and footer).

STEP 3: Add the JavaScript
---------------------------
Add this line at the bottom of your <body> section BEFORE the closing </body> tag:
<script src="./js/premium-interactions.js"></script>

STEP 4: Verify Fonts
---------------------
Make sure you have these Google Fonts loaded in your <head>:
<link href="https://fonts.googleapis.com/css2?family=Playfair+Display:wght@400;500;600;700;800;900&family=Inter:wght@100;200;300;400;500;600;700;800;900&display=swap" rel="stylesheet">

TROUBLESHOOTING
---------------
Issue: Animations not working
Solution: Make sure premium-interactions.js is loaded after the HTML content

Issue: Styles look different
Solution: Check that premium-styles.css loads AFTER your base styles

Issue: Particles not showing
Solution: Verify the particles container div exists in the HTML
