Typography System

The Three-Voice Hierarchy

Each typeface serves a specific emotional and functional purpose. Understanding when to deploy which voice is what transforms typography from decoration into strategic communication.

The Storyteller

Playfair Display

Editorial sophistication and emotional depth. The voice that makes you pause, lean in, and feel something.

When to use:

  • Hero headlines that need emotional weight
  • About page storytelling moments
  • Pull quotes and featured insights
  • Personal narrative headers

The Architect

Big Shoulders Display

Structural boldness and systematic clarity. The scaffolding made visible, the framework that holds everything together.

When to use:

  • Navigation and section headers
  • Portfolio project titles
  • Service/product names
  • Timeline milestones and card titles

The Translator

Inter

The connective tissue between emotion and structure. The bridge that makes everything readable, accessible, and human at scale.

When to use:

  • All body copy and paragraphs
  • UI elements and buttons
  • Form labels and metadata
  • Captions and supporting text

"This isn't indecision. This is orchestration. Every typeface has a purpose. Every moment has a voice."

Color System

Strategic Restraint

Six colors. Infinite impact. Each color is tied to a specific emotional and functional purpose. Use sparingly for maximum effect.

CORAL

Coral

#F96F6E

Strategy, leadership, primary CTAs. Use for Playfair Display accents and emotional anchor moments.

TEAL

Teal

#2ED3C6

Creative execution, innovation, delivery. Use for Big Shoulders Display accents and structural elements.

CLOUD DANCER

Cloud Dancer

#F3EFE0 • Pantone 2026

Warm neutrality, editorial calm. The connective tissue that softens the dark/light contrast. See implementation below.

FLOW

Gradient

Coral → Teal

Collaboration moments. Use sparingly for hybrid lockups or when emotion and structure converge.

DEPTH

Deep Blue

#2C3E50

Backgrounds, subtle accents, depth. Professional foundation that grounds the warmer tones.

GRAY

Cool Gray

#B2B2BB

Secondary text, borders, subtle UI elements. The neutral translator between bold statements.

Cloud Dancer Implementation

Pantone's 2026 Color of the Year brings warmth and editorial sophistication across the ecosystem. Cloud Dancer (#F3EFE0) serves as the connective neutral—neither stark white nor heavy gray.

Portfolio Applications

  • Background for About page hero sections
  • Card backgrounds in light mode
  • Section dividers and accent panels
  • Timeline milestone backgrounds

Hub & Insights

  • Article page backgrounds (Insights)
  • Service card accents (Hub)
  • Pull quote backgrounds
  • Footer sections for warmer grounding

Visual Language

Imagery & Iconography

Photography Style

  • High contrast, dramatic lighting
  • Authentic moments over staged poses
  • Urban and creative environments
  • Diverse, inclusive representation
  • Focus on human connection and emotion

Graphic Elements

  • Clean geometric shapes
  • Strategic use of coral accents
  • Minimal, purposeful design
  • Data visualization and infographics
  • Consistent spacing and alignment

Icon System

Custom SVG icons in brand colors only. Clean geometry, consistent strokes, zero emojis. Icons reinforce the sophisticated visual language.

Technical Specifications

  • Format: SVG primary, PNG (24-bit + alpha) when SVG not feasible
  • Colors: #F96F6E (Coral), #2ED3C6 (Teal) only
  • Stroke: 2px, rounded caps
  • ViewBox: 0 0 24 24
  • Sizes: 48px, 64px, 80px for UI
  • Naming: snake_case (e.g., vision.svg, connected-systems.svg)

"Emojis introduce inconsistent colors and platform-dependent rendering. Always use custom SVG icons in our brand colors."
