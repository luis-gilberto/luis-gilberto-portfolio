
Handoff: /workwithme Splash Intro (Coral Portal) — IMC Services Hub
Owner: Luis; Implementer: Trae

Goal
-----
When a user visits /workwithme they see a 3–4s brand splash video (Motion.mp4), with a small LG watermark and a Skip button, then they are routed to /IMCServices/. Users who go directly to /IMCServices/ should NOT see the splash.

Important Pathing (per Luis)
----------------------------
All assets live under the IMCServices directory level:

/IMCServices/assets/videos/Motion.mp4
/IMCServices/assets/images/LG-mark-coral.png
/IMCServices/assets/images/LG-mark-white.png

(If SVGs arrive later, same folder with .svg.)

0) PREREQS
----------
- Disable any server-side redirect of /workwithme → /IMCServices/ (Cloudflare/Netlify/WP).
- Upload the video and watermark(s) to the exact paths above.

1) ROUTE & FILE PLACEMENT
-------------------------
We want /workwithme to be a REAL route that renders a simple HTML page, then client-side navigates to /IMCServices/ after the splash.

Static site structure:
  /workwithme/
      index.html        ← splash page (contents below)
  /IMCServices/
      assets/
        videos/Motion.mp4
        images/LG-mark-coral.png
        images/LG-mark-white.png

(If the project enforces a different pages folder, mirror that convention; the key requirement is that /workwithme resolves to this index.html.)

2) SPLASH PAGE (index.html) — FULL CONTENTS
-------------------------------------------
Paste the following into /workwithme/index.html. The paths already point to the IMCServices assets.

<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1" />
  <title>Entering the Hub…</title>

  <!-- Preload for snappy start -->
  <link rel="preload" as="video" href="/IMCServices/assets/videos/Motion.mp4" type="video/mp4">

  <style>
    :root{
      --coral:#F96F6E;
      --ink:#000;
    }
    html,body{height:100%;margin:0;background:#000}

    /* Fullscreen overlay container */
    #splash{
      position:fixed; inset:0; z-index:9999;
      display:grid; place-items:center; overflow:hidden;
      background:
        radial-gradient(120% 120% at 50% 60%, rgba(249,111,110,.18) 0%, rgba(249,111,110,.08) 35%, rgba(0,0,0,.9) 60%, #000 100%),
        #000;
    }
    /* Subtle animated coral glow */
    #splash:before{
      content:""; position:absolute; inset:-10%;
      background: radial-gradient(60% 40% at 50% 70%, rgba(249,111,110,.22), transparent 60%);
      filter: blur(40px); opacity:.7; animation: glow 3s ease-in-out infinite alternate;
      pointer-events:none;
    }
    @keyframes glow{ from{opacity:.5} to{opacity:.9} }

    /* Video element */
    #splash video{
      max-width:min(100%,1400px);
      max-height:100vh;
      object-fit:contain;
      display:block;
      filter: contrast(1.02) saturate(1.02);
    }

    /* Watermark (swap to white version if needed) */
    .lg-watermark{
      position:fixed; right:22px; bottom:18px; width:46px; height:auto;
      opacity:0; filter: drop-shadow(0 0 10px rgba(249,111,110,.35));
      animation: markIn .6s ease 0.9s forwards;
      pointer-events:none;
    }
    @keyframes markIn{ to{opacity:.45} }

    /* Skip button */
    .skip{
      position:fixed; left:16px; bottom:16px; z-index:10000;
      background:rgba(0,0,0,.55); color:#fff; border:1px solid rgba(255,255,255,.25);
      padding:.5rem .75rem; border-radius:999px; font:500 12px/1 Inter, system-ui;
      letter-spacing:.02em; cursor:pointer; user-select:none;
      backdrop-filter: blur(4px);
      transition: transform .2s ease, background .2s ease, border-color .2s ease;
    }
    .skip:hover{ transform: translateY(-1px); background:rgba(0,0,0,.7); border-color:rgba(255,255,255,.4) }

    /* Fade out overlay */
    .fade-out{ animation: fadeOut .8s ease forwards; }
    @keyframes fadeOut{ to{ opacity:0; visibility:hidden } }

    /* Reduced motion respect */
    @media (prefers-reduced-motion: reduce){
      #splash:before{ animation:none }
      .lg-watermark{ animation:none; opacity:.45 }
    }
  </style>
</head>
<body>

  <!-- Splash overlay -->
  <div id="splash" aria-label="Intro animation">
    <video id="splash-video" autoplay muted playsinline>
      <source src="/IMCServices/assets/videos/Motion.mp4" type="video/mp4">
    </video>
  </div>

  <!-- Watermark: choose one -->
  <img class="lg-watermark" src="/IMCServices/assets/images/LG-mark-coral.png" alt="Luis Gilberto mark">
  <!-- alt: <img class="lg-watermark" src="/IMCServices/assets/images/LG-mark-white.png" alt="Luis Gilberto mark"> -->

  <!-- Skip -->
  <button class="skip" type="button" aria-label="Skip intro">Skip</button>

  <script>
    (function(){
      const splash = document.getElementById('splash');
      const vid    = document.getElementById('splash-video');
      const skip   = document.querySelector('.skip');

      const go = () => {
        splash.classList.add('fade-out');
        setTimeout(()=> window.location.href = "/IMCServices/", 700);
      };

      vid.addEventListener('ended', go);

      // Fallback in case 'ended' doesn't fire; adjust if clip is longer than ~4s
      const FALLBACK_MS = 4000;
      const t = setTimeout(go, FALLBACK_MS);

      skip.addEventListener('click', () => { clearTimeout(t); go(); });

      vid.play().catch(()=>{});
    })();
  </script>
</body>
</html>

3) OPTIONAL: ONCE-PER-SESSION LOGIC
-----------------------------------
If you want the splash to show only once per browser session:
- Add this at the TOP of the <script> IIFE:

    if (sessionStorage.getItem('seenWorkWithMe') === '1') {
      window.location.replace('/IMCServices/');
    }

- And set the flag just before redirect, inside go():

    sessionStorage.setItem('seenWorkWithMe','1');

4) TEST PLAN
------------
- Confirm no server-side redirect exists for /workwithme.
- Visit /workwithme:
  • Video autoplays (muted, inline), watermark glows, Skip is visible.
  • On end (or ~4s fallback), overlay fades and route changes to /IMCServices/.
- Visit /IMCServices/ directly: no splash.
- Mobile Safari: verify autoplay and redirect behavior.

5) TROUBLESHOOTING
------------------
- If you see an instant jump to /IMCServices/: a server-side redirect is still active.
- If video doesn’t play on iOS: ensure the source path is correct and the video is H.264 MP4; muted + playsinline set.
- If watermark looks too bright/dim: swap coral ↔ white or tweak CSS opacity/drop-shadow.

6) NOTES
--------
- We can reuse this approach for other vanity routes.
- You can swap Motion.mp4 at any time without touching code.
